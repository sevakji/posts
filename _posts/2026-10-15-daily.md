# Daily digest — 2026-10-15

> Today's feed is agentic coding maturing on two fronts: tooling ships (OpenCode 2.0, Jev 1.14.0 with experimental "dreamers"), while practice lags — mob programming breaks under agents, skills files are bloated, and harness design now needs its own crash course. Liquid AI's LFM2.5-24B-A2B is the sleeper pick, built specifically for fast on-device agents, which matters if you're running this stuff on homelab hardware instead of burning API credits. Also worth internalizing: the "rogue AI hacker" reports are being attributed to containment and monitoring failures, not model misbehavior — a deployment problem, not a model problem. On infra, pg_vectorsearch claims to beat pgvector's IVFFlat and HNSW on speed; worth benchmarking if you're building RAG on Postgres.
