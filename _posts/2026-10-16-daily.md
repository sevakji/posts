# Daily digest — 2026-10-16

> Agentic coding has clearly crossed from demo to production—Uber's Minion is landing 15% of PRs, and the day's talks converge on the same playbook: delegate real work, engineer context deliberately, and treat evals as the release gate, not an afterthought. The failure-mode framing is the useful part; most agent projects die on context and eval mistakes, not model quality. On the security side, AdFection shows the same ad-tech plumbing that would let agents spend your money being weaponized for zero-click mercenary spyware via targeted ads. If you only watch two things: the Uber case study and the evals talk.
