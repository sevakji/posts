# Daily digest — 2026-10-23

> Today's feed reads like agentic coding growing up: the "vibe coding" era is giving way to spec-driven workflows, code review as a first-class skill, and repo-scale tooling built on ASTs and LSP. The infrastructure layer is maturing too — NVIDIA's OpenShell for sandboxing agent fleets and Anthropic's work on LLM-assisted formal verification both signal that trust, not capability, is now the bottleneck. Meanwhile Fireship's "last real programmers" and the Ask HN thread on why OpenAI doesn't just spin up 100 companies frame the same question from opposite ends: what exactly is left for humans when agents write the code? The practical answer buried in today's items — write fewer, better evals and review everything — is the closest thing to a job description.
