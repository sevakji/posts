# Daily digest — 2026-11-15

> The throughline today is that the moat is moving from models to orchestration: Andrew Ng says the opportunities are in vertical applications, the "AI has eaten tactical programming" piece argues the coding layer is already agent territory, and A2A plus "your next customer isn't human" push the same thesis out to tooling and buyers. Frontier capability is commoditizing fast — someone replicated DeepSeek V3 in ~200 lines of pure JAX, which makes Ng's "build on top, don't train" advice feel like a practical constraint rather than a platitude. The cautionary tale is Lovable: deployed apps leaking passport details and 200K+ private messages is what happens when vibe-coding velocity meets no security primitives. If you're running Claude agents overnight, today's workflow tips plus PyPI's new security signals are the low-effort hygiene items to adopt first.
